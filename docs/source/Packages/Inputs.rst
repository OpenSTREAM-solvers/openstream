Inputs
======

The :mod:`Inputs` package defines a set of classes used to configure and import all the necessary parameters for running **OpenSTREAM** simulations. This includes:

- Boundary conditions
- System geometry
- Physical models
- Numerical options
- Fluid thermophysical properties

These input definitions form the backbone of each simulation setup, ensuring consistency, flexibility, and clarity across different solver frameworks.
