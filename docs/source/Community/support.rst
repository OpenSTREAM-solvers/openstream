Support
=======

The best way to get help is by using the `tracker <https://github.com/mfval/TwoPhaseSolver/issues>`_. The :ref:`maintainers <Maintainers>` are usually notified of new issues and will try to respond quickly. A real-time support system is not implemented, yet.

GitHub: `https://github.com/mfval/TwoPhaseSolver/issues <https://github.com/mfval/TwoPhaseSolver/issues>`_
