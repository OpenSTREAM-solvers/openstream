CoolPropWrapper
===============

The :mod:`CoolPropWrapper` package is designed to serve as a MATLAB interface to the CoolProp thermophysical property library, which is a Python-based library for calculating fluid properties.

More information about the CoolPropWrapper can be found at https://github.com/mfval/CoolPropWrapper.

Information about CoolProp can be found at https://coolprop.org.
