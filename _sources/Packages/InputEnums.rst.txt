InputEnums
==========

The :mod:`InputEnums` package defines a set of enumeration classes used to specify valid options for physical models in OpenSTREAM. These enums help ensure consistency and clarity when selecting model configurations, making the simulation setup more robust and less error-prone.

Typical examples include choosing between void fraction models, interfacial transfer options, or flow regime assumptions, each represented by a clearly defined enum.
